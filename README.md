## Overview

AUDIO.TUI is an interactive music player designed to run inside a terminal. Its compact text interface emphasizes fast movement through audio sources, immediate playback feedback, and straightforward controls for users who prefer a console-based workflow.

Alongside local file browsing and playback, the application supports online radio and system audio integration. These capabilities bring source selection, listening, and live visual output together without requiring a separate graphical player.
